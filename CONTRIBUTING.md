# Contributing

Issues and small pull requests are welcome.

- Keep the app client-side. Do not add an account, analytics, or an upload of bill data.
- Do not add paid features, license checks, or shop keys to this repository.
- Keep the claims conservative: Swiss Payment Standards version 2.3, not certified, not affiliated with SIX, no guarantee that a bank accepts every bill.
- Use Swiss spelling in German UI text: ss, not ß.
- Run `npm test` before you open a pull request.

Report bugs with the issue template. Include the browser, the currency, and whether the account was a QR-IBAN or a normal IBAN. Do not include a real customer's name, address, or IBAN.
